# OBDisplay-Uno Wiki

KWP-1281 K-Line trip computer for Arduino Uno with SH1107 OLED display. Reads live sensor data and fault codes from VAG vehicles (Golf Mk4, Bora, Jetta, ~1998–2006) over the K-Line OBD interface.
